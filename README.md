# POCKET MANAGER — 0.1.0-alpha

Application Android de gestion financière (Kotlin, Jetpack Compose, SQLite). Android 9 minimum. Version alpha destinée aux essais avec des données fictives.

Comptes multiples, catégories personnalisées, revenus, dépenses, transferts et frais, budgets mensuels, souhaits, cinq thèmes et assistant local. Export/restauration manuels chiffrés via un fournisseur de documents Android compatible, notamment Google Drive si disponible.

La sauvegarde automatique Google Drive, la biométrie, le chiffrement de la base locale et les fonctionnalités avancées ne sont pas encore implémentés. Ne pas utiliser cette alpha avec des données financières réelles.

GitHub Actions : Android alpha APK. Télécharger l'artefact Pocket-Manager-alpha-APK après une compilation réussie. APK de débogage ; la signature de production stable sera nécessaire pour les mises à jour durables.
